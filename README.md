# Iris Flower Classification

Machine Learning classification project using the Iris dataset to predict flower species.

### Dataset
- 150 observations
- 4 features
- 3 classes: Setosa, Versicolor, Virginica

### Algorithms
- Support Vector Classifier (SVC)
- K-Nearest Neighbors (KNN)
- Logistic Regression
- Gaussian Naive Bayes

### Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
